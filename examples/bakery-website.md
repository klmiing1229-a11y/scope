# Example: `scope` on a vague wish

**User:** scope build me a website for my bakery

**Scope asks (one message):**
1. Who is it for? a) local walk-in customers (default) b) wholesale buyers c) both
2. What does done look like? (default) a visitor can see the menu, opening hours and where you are
3. Limits? (default) free hosting, no online payments, ready this week
4. What exists already? Logo, photos, a menu doc? (default) none
5. Out of scope? (default) online ordering, blog, multiple languages

**User:** ok, but we have photos and a PDF menu

**Brief:**

**Wish:** build me a website for my bakery
**Scoped as:** a one-page website for walk-in customers showing the menu, hours and location.

**For:** local walk-in customers
**Done when:**
- The page shows the menu (from the PDF), opening hours and a map link
- It reads correctly on a phone
- It is live on a free host with a shareable link

**Limits:** free hosting, no payments, this week
**Start from:** existing photos and PDF menu
**Out of scope (for now):** online ordering, blog, multiple languages
**Assumed:** Chinese and English are not both needed

**First step:** extract the menu text from the PDF and lay out the page sections.

Run it? (ok / change X / just the brief)
